## Overview

Medora is a hospital EMR and operations platform. This guide orients clinical, billing, inventory, and administration teams.

## First login

1. Use your hospital-issued staff account.
2. Complete two-factor authentication when prompted.
3. Select user group and branch if your hospital uses them.

## Find help

- Use **Ctrl+K** on `/docs` to search workflows.
- In the hospital app, click the **?** icon to open documentation for the current screen.

## Next steps

- Browse [modules](/docs/modules/administration) for your department.
- Read [coding standards](/docs/guides/coding-standards) for diagnosis search.
