- **Change:** The eMAR tab is now a line × time MAR built by the previously orphaned `buildMarGrid`, with PRN and continuous-infusion cards, the BCMA scan dialog wired to a single `LEmarDoseDialogContent` instance, and a print sheet. `ensureSchedulesForVisit` replaces `generateSchedulesForLine`: it plans doses with the pure `planDosesForWindow` (UTC-anchored via `parseUtcInstant`, capped at start + duration through the existing `addDurationToStart`, PRN and continuous infusion excluded by the shared `isOnDemandLine`) and inserts with `onConflictDoNothing` against a new `med_order_schedule_line_at_uidx`. `getEmarMar` serves identity, bed location, lines, due doses and charted doses; the bed comes from one query using `coalesce(open ipd_bed_stay_segment, ipd_admission)` with `admission_status = ADMITTED`. `recordAdministration` now requires a `MedicationHoldReasonEnum` code for any non-`given` status, requires the patient and nurse scans only for `given`, rejects a second `given` on the same due instant, and applies the PRN interval only to PRN lines. `recordInfusionEvent` writes start/stop markers as `INFUSION_START` / `INFUSION_STOP` administrations with `schedule_id = null`, and `MarLine.infusionRunning` reads the latest marker.
