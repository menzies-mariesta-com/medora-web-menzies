# 1. Add a new language

## 1.1 Go to settings.json in project.inlang

path `project.inlang/settings.json`

In locales string array, add a new language code. (eg: `en`)

## 1.2 Add that new language in language enum

path `src/lib/model/enum/language.enum.ts`

With Country and Code. (eg. "ENGLISH" = "en")

## 1.3 Create json file

path `messages`

with language code. (eg. en.json). check other language and align the content.
